# Quiz Drill

ブラウザだけで動作する、問題データ差し替え式のクイズ・学習ドリルです。

`quiz-data.js` を編集することで、タイトル、説明、分野、問題、合格点、制限時間などを変更できます。資格試験対策、社内研修、小テスト、暗記ドリルなどに利用できます。

同梱の問題データは、AWS Certified Solutions Architect - Associate（SAA-C03）の出題範囲をもとに独自作成した非公式の学習用ドリルです。

> このプロジェクトはAWS公式の教材・模擬試験ではありません。AWSによる提供、承認、提携、保証を受けたものではなく、問題は学習目的で独自に作成しています。

問題データを差し替えて使える、ブラウザ完結型のクイズ・学習ドリル。タイマー、復習、分野別スコア、単一/複数選択に対応。

A browser-based quiz drill app with swappable question data, timer, review mode, domain scoring, and single/multiple-choice support.

## 使い方

1. `quiz-app.html` をブラウザで開く（サーバー不要）
2. 出題分野と問題数を選択
3. 「試験を開始する」をクリック
4. 回答・フラグを使いながら全問を解く
5. 「見直し」→「提出する」でスコアを確認
6. 「解答を確認する」で全問の解説を読む

## 機能

| 機能 | 詳細 |
|---|---|
| 分野選択 | 出題分野をチェックボックスで選択（未選択分野は出題対象外） |
| 問題数の選択 | スライダーで問題数を選択（選択分野の問題数を超える場合は自動調整） |
| 自動タイマー | 問題数 × 1問あたりの制限時間（分） |
| 問題形式 | 単一選択・複数選択の混在 |
| フラグ機能 | 後で見直したい問題に🚩を付けて保留 |
| ナビゲーター | 全問の回答状況を色分けで一覧表示 |
| 見直し画面 | 提出前に回答済み／フラグ／未回答を確認 |
| スコア算出 | スケールドスコア（設定した点数範囲・合格ラインで判定） |
| 分野別結果 | 各分野の正答率をグラフで表示 |
| 解答レビュー | 全問の正誤・解説を提出後に確認 |

## 問題データ・設定のカスタマイズ

`quiz-data.js` に `QUIZ_CONFIG`（アプリ全体の設定）と `QUESTION_BANK`（問題データ）を定義しています。この2つを書き換えるだけで、別のクイズに転用できます。

```js
const QUIZ_CONFIG = {
  title: 'クイズのタイトル',
  subtitle: 'サブタイトル（小さく表示される見出し）',
  description: 'クイズの説明文',
  passScore: 720,        // 合格スコア
  scoreMin: 100,          // スコアの最小値
  scoreMax: 1000,         // スコアの最大値
  defaultQuestionCount: 65, // 初期の出題数
  maxQuestionCount: 65,     // 出題数スライダーの上限
  minutesPerQuestion: 2,    // 1問あたりの制限時間（分）
  domains: {
    1: '分野1の名前',
    2: '分野2の名前',
    // 分野は自由に追加・削除できます
  },
  disclaimer: '免責文（任意）'
};

const QUESTION_BANK = [
  {
    d: 1,               // 分野番号（domainsのキーに対応）
    dn: '分野1の名前',
    t: '問題文',
    type: 'single',      // 'single'（単一選択）または 'multi'（複数選択）
    opts: [
      { id: 'A', txt: '選択肢A' },
      { id: 'B', txt: '選択肢B' },
    ],
    correct: ['A'],       // 正解の選択肢ID（複数選択は複数指定）
    exp: '解説文',
  },
  // 問題を追加していく
];
```

分野を増減させたり、`type: 'multi'` の場合は `choose: 2`（選択すべき数）を問題オブジェクトに追加してください。
